TOLU AKINPELU PERSONAL WEBSITE

Open index.html in a browser to preview. It is a static site: host the whole folder on Netlify, Vercel, GitHub Pages or any web host.

Everything lives inside index.html (switched by the menu or by links):
Home, About, Selected work, Testimonials, Currently, Contact, plus the click-through pages
The High-Performing Freelancer (#/freelancer), How I work with brands (#/work-with-me),
and two essays that open as their own pages (essays/notcoin.html and essays/rug-test.html). Keep the folder structure as it is.

HOW TO UPDATE
1. Currently: find "TO ADD AN ENTRY", copy one <article class="entry"> block, paste it below the last one and change the label, title and sentence.
2. Book photo: replace assets/storytelling-animal.jpg to change the book in Currently.
3. Testimonials: they have their own page and menu item. Find "TO ADD A TESTIMONIAL" and copy one <figure class="testi"> block. The last testimonial is unattributed (empty <figcaption>).
4. Bitoshi pieces: in the Selected work page, copy one <a role="listitem"> row.
5. Email, LinkedIn, Substack and Drive links appear in several places. Search for the old link and replace it everywhere.

The theme toggle (light and dark) remembers the visitor's choice. Text appears word by word as it scrolls into view; this is switched off automatically for visitors who prefer reduced motion.

MOBILE NAVIGATION
On phones and tablets a fixed bar at the bottom of every page links to About, Selected work, Testimonials, Currently and Contact, so nobody has to find the Menu button first. The home page also shows the same links as buttons under the portrait (class "explore").
